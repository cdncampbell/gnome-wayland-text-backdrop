# Keyboard Shortcuts

> Press **Super** and start typing to search for _anything_.

## Windows

| Shortcut          | Action                        | Notes       |
|-------------------|:-----------------------------:|------------:|
| `Super`+`Up`      | Maximise                      | toggle      |
| `Super`+`Left`    | Tile left                     |             |
| **Alt**+Tab       | Switch applications           | hold Alt    |
| Alt+`F4`          | Close window                  | ~~Ctrl+Q~~  |
| Ctrl+Alt+`<Del>`  | Log out & power options       | confirm     |

## Workspaces

- **Super**+Page Up / Page Down: previous / next workspace
- **Shift**+Super+Page Up: move the window along
  * hold *Alt* to skip empty ones
    + works with the mouse wheel too
1. Open the overview
2. Drag a window to a workspace thumbnail

---

## Text editing

### Selection

- `Ctrl`+`A` select all
- `Ctrl`+`Shift`+`Left` select a word to the left
- Double-click selects a word; triple-click selects the line

### Clipboard

Ctrl+C copies, Ctrl+V pastes, and Ctrl+Shift+V pastes as plain text.
Use \*literal\* stars, keep snake_case_names and 2*3*4 as they are.
